## 2. 多租户隔离架构

```

                                ↓

## 3. Docker容器生命周期

```
┌─────────────────────────────────────────────────────────────────┐
│                     服务启动                                      │
│  1. 扫描所有 sandbox-* 容器                                      │
│  2. 从容器名提取 thread_id                                       │
│  3. 检查 Thread 表是否存在                                       │
│     ├─ 存在: 重建 Redis 映射                                     │
│     └─ 不存在: 删除孤儿容器                                      │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   首次 API 请求                                   │
│  POST /api/chat/{thread_id}                                     │
│     ↓                                                            │
│  get_thread_backend(thread_id)                                  │
│     ↓                                                            │
│  懒加载创建容器:                                                  │
│    - 名称: sandbox-{thread_id}                                  │
│    - 挂载: workspace + shared + skills                          │
│    - 资源: CPU 1核 + 内存2G                                      │
│    - 启动: sleep infinity                                        │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   容器使用中                                      │
│  每次 execute/upload/download:                                   │
│    1. 更新 Redis: last_active_at = now()                        │
│    2. 执行操作                                                   │
│    3. 返回结果                                                   │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                  后台清理任务 (每60秒)                            │
│  扫描 Redis:                                                     │
│    for key in r.scan_iter("sandbox:*"):                         │
│        last_active = r.hget(key, "last_active_at")              │
│        if now - last_active > 60秒:                             │
│            删除容器                                              │
│            删除 Redis 记录                                       │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                  Thread 超时清理 (72小时)                         │
│  扫描 Thread 表:                                                 │
│    for thread in expired_threads:                               │
│        1. await checkpointer.adelete_thread(thread_id)         │
│        2. 删除容器 sandbox-{thread_id}                          │
│        3. r.delete(f"sandbox:{thread_id}")                      │
│        4. db.delete(Thread)                                     │
└─────────────────────────────────────────────────────────────────┘
```

## 4. SSE流式输出流程

```
用户发送消息
     ↓
POST /api/chat/{thread_id}
     ↓
┌─────────────────────────────────────────────────────────────────┐
│                 AgentStreamRunner                                │
│  agent.astream(                                                 │
│    input,                                                       │
│    stream_mode=["messages", "updates"],  ← 实测正确的配置       │
│    subgraphs=True                        ← 统一数据格式         │
│  )                                                              │
└─────────────────────────────────────────────────────────────────┘
     ↓
┌─────────────────────────────────────────────────────────────────┐
│              流式输出事件 (SSE)                                   │
│                                                                  │
│  stream_mode == "messages":                                     │
│    → (AIMessageChunk, metadata)                                 │
│    → 检测 tool_calls: event: tool_start                         │
│    → 输出 content: event: content                               │
│                                                                  │
│  stream_mode == "updates":                                      │
│    → {"tools": ...}: event: tool_end                            │
│    → {"__interrupt__": ...}: event: interrupt                   │
│                                                                  │
│  异常处理:                                                        │
│    → event: error                                               │
│                                                                  │
│  结束:                                                            │
│    → event: done                                                │
└─────────────────────────────────────────────────────────────────┘
     ↓
前端实时渲染
```

│  4. SSE返回: event: interrupt                                   │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   前端显示确认对话框                              │
│  ┌────────────────────────────────────┐                        │
│  │  Agent想要执行命令:                │                        │
│  │  rm data.txt                       │                        │
│  │                                    │                        │
│  │  [继续]  [取消]                    │                        │
│  └────────────────────────────────────┘                        │
└─────────────────────────────────────────────────────────────────┘
                                ↓
                ┌───────────────┴───────────────┐
                ↓                               ↓
┌──────────────────────────┐    ┌──────────────────────────┐
│   用户点击"继续"          │    │   用户点击"取消"          │
│   POST /api/resume       │    │   POST /api/resume       │
│   {action: "continue"}   │    │   {action: "cancel"}     │
└──────────────────────────┘    └──────────────────────────┘
                ↓                               ↓
┌──────────────────────────┐    ┌──────────────────────────┐
│  Command(resume={        │    │  Command(resume={        │
│    "decisions": [{       │    │    "decisions": [{       │

│  })                      │    │  })                      │
└──────────────────────────┘    └──────────────────────────┘
                ↓                               ↓
┌──────────────────────────┐    ┌──────────────────────────┐
│  执行命令: rm data.txt    │    │  跳过命令执行             │
│  返回结果                 │    │  返回取消信息             │
└──────────────────────────┘    └──────────────────────────┘
```

## 6. auto_resume机制 (build模式)

```
┌─────────────────────────────────────────────────────────────────┐
│                   Build模式 (执行模式)                           │
│  mode = "build"                                                 │
│  AUTO_APPROVE_TOOLS = {"execute", "write_file", "edit_file"}   │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                    Agent执行流程                                 │
│  1. Agent调用: execute("pip install numpy")                    │
│  2. 触发 interrupt_on={"execute": True}                         │
│  3. 检测: tool_name in AUTO_APPROVE_TOOLS?                     │
│     → Yes: auto_resume = True                                   │
│     → No: 返回 interrupt 事件给前端                              │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   自动批准并继续                                 │
│  if auto_resume:                                                │
│      Command(resume={"decisions": [{"type": "approve"}]})      │
│      自动执行，无需用户确认                                       │
└─────────────────────────────────────────────────────────────────┘

对比:

┌─────────────────────────────────────────────────────────────────┐
│                   Plan模式 (思考模式)                            │
│  mode = "plan"                                                  │
│  所有操作都需要用户确认                                          │
└─────────────────────────────────────────────────────────────────┘
```

## 7. Thread清理完整流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     Thread 表 (唯一真实来源)                     │
│  thread_id          | user_id  | last_active_at                │
│  --------------------|----------|-------------------------------│
│  user001-uuid-1     | user001  | 2026-03-05 10:00:00           │
│  user001-uuid-2     | user001  | 2026-03-02 08:00:00 ← 超时    │
│  user002-uuid-1     | user002  | 2026-03-05 11:00:00           │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│              后台清理任务 (每5分钟)                               │
│  cutoff_time = now() - 72小时                                   │
│  expired_threads = SELECT * FROM threads                        │
│                    WHERE last_active_at < cutoff_time           │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│              对每个超时Thread执行清理                             │
│                                                                  │
│  Thread: user001-uuid-2                                         │
│    ↓                                                             │
│  1. 删除 Checkpoint (PostgreSQL)                                │
│     await checkpointer.adelete_thread("user001-uuid-2")        │
│    ↓                                                             │
│  2. 删除容器 (Docker)                                            │
│     container = docker.get("sandbox-user001-uuid-2")            │
│     container.remove(force=True)                                │
│    ↓                                                             │
│  3. 删除Redis记录                                                │
│     r.delete("sandbox:user001-uuid-2")                          │
│    ↓                                                             │
│  4. 删除Thread记录                                               │
│     DELETE FROM threads WHERE thread_id = "user001-uuid-2"     │
└─────────────────────────────────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────┐
│                     服务启动                                      │
│  1. 扫描Docker: 列出所有 sandbox-* 容器                          │
│  2. 扫描Redis: 列出所有 sandbox:* 键                             │
│  3. 扫描PostgreSQL: 列出所有 Thread 记录                         │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   三方数据对比                                    │
│                                                                  │
│  Docker容器:  [sandbox-A, sandbox-B, sandbox-C]                │
│  Redis键:     [sandbox:A, sandbox:B]                            │
│  Thread记录:  [A, B]                                             │
│                                                                  │
│  分析:                                                           │
│    - 容器C: Thread表不存在 → 孤儿容器 → 删除                     │
│    - 容器A、B: Thread表存在 → 保留 → 重建Redis映射               │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   执行同步操作                                    │
│                                                                  │
│  孤儿容器 (sandbox-C):                                           │
│    container.remove(force=True)                                 │
│    r.delete("sandbox:C")                                        │
│                                                                  │
│  重建映射 (sandbox-A, sandbox-B):                                │
│    r.hset("sandbox:A", {                                        │
│      "container_id": "...",                                     │
│      "last_active_at": time.time()                              │
│    })                                                           │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   同步完成                                        │
│  Thread表 = 唯一真实来源                                          │
│  Redis = 从Thread表同步                                          │
│  Docker = 从Thread表同步                                          │
└─────────────────────────────────────────────────────────────────┘
```

## 9. WebDAV与Agent文件同步

```
改造前 (Thread级隔离):
┌─────────────────────────────────────────────────────────────────┐
│  workspaces/                                                     │
│  └── user_001/                                                   │
│      ├── user_001-thread-abc/    ← Agent在这里工作              │
│      │   └── project/                                           │
│      └── shared/                  ← WebDAV上传到这里            │
│          └── upload.txt           ← Agent看不到！               │
└─────────────────────────────────────────────────────────────────┘

改造后 (用户级共享):
┌─────────────────────────────────────────────────────────────────┐
│  workspaces/                                                     │
│  └── user_001/                   ← 共享工作目录                  │
│      ├── project/                ← Agent和WebDAV都操作这里      │
│      ├── data.txt                ← Agent创建的文件              │
│      └── upload.txt              ← WebDAV上传的文件             │
│                                                                  │
│  Container A (thread-abc):                                       │
│    /workspace → workspaces/user_001/ (rw)                       │
│                                                                  │
│  Container B (thread-def):                                       │
│    /workspace → workspaces/user_001/ (rw)  ← 挂载同一目录        │
│                                                                  │
│  WebDAV操作:                                                     │
│    PUT /dav/user_001/upload.txt                                 │
│      → workspaces/user_001/upload.txt                           │
└─────────────────────────────────────────────────────────────────┘

优势:
✅ Agent立即可见WebDAV上传的文件
✅ 同一用户所有Thread共享文件
✅ 容器环境隔离（pip安装互不影响）
```

## 10. 错误处理流程

```
┌─────────────────────────────────────────────────────────────────┐
│                   API层错误处理                                   │
│  try:                                                            │
│      verify_thread_permission(user_id, thread_id)               │
│      result = await agent_manager.stream_chat(...)              │
│      return StreamingResponse(result)                           │
│  except HTTPException:                                          │
│      raise  # 直接抛出 (401, 403, 404)                          │
│  except Exception as e:                                         │
│      raise HTTPException(500, str(e))                           │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   Agent层错误处理                                 │
│  async def stream_chat(...):                                    │
│      try:                                                        │
│          async for chunk in agent.astream(...):                 │
│              yield formatter.format(chunk)                      │
│      except Exception as e:                                     │
│          yield f"event: error\ndata: {str(e)}\n\n"              │
│      finally:                                                    │
│          yield "event: done\ndata: {}\n\n"                      │
└─────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────┐
│                   Docker层错误处理                                │
│  def execute(self, command: str):                               │
│      try:                                                        │
│          container = self._ensure_container()                   │
│          exit_code, output = container.exec_run(...)            │
│          return ExecuteResponse(...)                            │
│      except docker.errors.APIError as e:                        │
│          print(f"[DockerSandbox] Error: {e}")                   │
│          raise                                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 总结

这些架构图展示了项目的核心设计：

1. **三层隔离**: 用户级 → Thread级 → 环境级
2. **懒加载**: 容器按需创建，节省资源
3. **唯一真实来源**: Thread表为基准，其他组件同步
4. **幂等清理**: 所有清理操作可安全重复
5. **防御性编程**: 多层错误处理，finally确保资源释放
